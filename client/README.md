# 📖 Project Overview

This project is a complete redesign of the Krishna International School website. The goal was to transform the existing website into a modern, responsive, and premium web application while improving user experience, accessibility, visual appeal, and performance.

The redesign focuses on creating a clean, engaging interface with reusable components, smooth animations, and a fully responsive layout suitable for all screen sizes.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/SrihariWebDeveloper/DETTROIN-INT--kisaligarhWebsite.git
```

Navigate into the project

```bash
cd clent
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
